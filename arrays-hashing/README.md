# Arrays & Hashing

Java solutions to Data Structures & Algorithms problems focused on **arrays, hash maps, hash sets, frequency counting, and related problem-solving patterns**.

The goal of this repository is to document clean, efficient solutions while developing a strong understanding of **why a particular pattern works and when to use it**.

## Core Patterns

- Hash Map & Hash Set
- Frequency Counting
- Complement / Lookup Techniques
- Prefix & Suffix
- In-place Array Manipulation

## Solution Approach

Each solution is written in **Java** with emphasis on:

- Clear and readable implementation
- Appropriate data-structure selection
- Time and space complexity
- Recognizing the underlying problem-solving pattern
